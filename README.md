# Captive Portal Detector (كاشف بوابات الدخول)

تطبيق أندرويد مفتوح المصدر مصمم لمراقبة اتصالات الشبكة في الخلفية واكتشاف بوابات الدخول (Captive Portals) تلقائيًا، مع إشعار فوري ومتصفح مدمج مقيّد بالشبكة لإتمام المصادقة والوصول إلى الإنترنت بسهولة.

---

## 🎯 الميزات الرئيسية

- **مراقبة مستمرة في الخلفية:** خدمة مستمرة (Foreground Service من نوع `dataSync`) متوافقة مع Android 14 و Android 15، مع دعم `onTimeout`.
- **كشف مزدوج متقدم:**
  - فحص معيار **RFC 8908** على مستوى النظام (Android 11+).
  - فحص نقاط نهاية HTTP (`generate_204`) مع منع تتبع التحويلات للتعرف الفوري على أكواد `301/302/307/308` أو صفحات `200 OK` الخاصة بالبوابات.
- **إشعارات ذكية وغير مزعجة:**
  - إشعار دائم يعرض حالة المراقبة والاتصال.
  - إشعار تنبيهي مرتفع الأولوية عند رصد بوابة دخول مع نافذة منع التكرار (Deduplication) لمدة 60 ثانية.
- **متصفح مدمج ومقيّد بالشبكة (`CaptivePortalLoginActivity`):**
  - استخدام `bindProcessToNetwork` لضمان توجيه حركة المرور حصرياً عبر الشبكة غير المصادق عليها، حتى لو كان الجهاز متصلاً ببيانات الهاتف.
  - دعم ملفات تعريف الارتباط (Cookies) وجافاسكريبت وDOM Storage الضرورية لبوابات الفنادق والمطارات والمقاهي.
  - إعادة فحص الاتصال تلقائياً فور إنهاء تسجيل الدخول.
- **طبقة استمرارية احتياطية (WorkManager):**
  - فحص دوري في وضع السكون (Doze Mode).
  - استئناف المراقبة بعد إعادة تشغيل الجهاز عبر `BootReceiver`.
- **واجهة مستخدم حديثة وسجل كامل:**
  - مبنية بتقنية **Jetpack Compose** و **Material 3**.
  - بطاقة فحص يدوي فورية وزر لتشغيل/إيقاف الخدمة.
  - قاعدة بيانات محلية **Room** لحفظ سجل كامل للأحداث والشبكات المكتشفة.

---

## 🏗️ المتطلبات التقنية

- **الحد الأدنى للنظام:** Android 8.0 (API 26)
- **الإصدار المستهدف:** Android 15 / 16 (API 35-36)
- **لغة البرمجة:** Kotlin (2.x)
- **واجهة المستخدم:** Jetpack Compose (Material 3)
- **قاعدة البيانات:** Room Database
- **الخدمات:** Foreground Service (`dataSync`), WorkManager

---

## 🔐 الصلاحيات والأمان

- `INTERNET` & `ACCESS_NETWORK_STATE`: للتحقق من الاتصال ومراقبة تغيرات الشبكة.
- `ACCESS_WIFI_STATE`: لقراءة معلومات شبكة الواي فاي.
- `POST_NOTIFICATIONS`: لإرسال التنبيهات (Android 13+).
- `FOREGROUND_SERVICE` & `FOREGROUND_SERVICE_DATA_SYNC`: لاستمرار الخدمة في الخلفية.
- `RECEIVE_BOOT_COMPLETED`: لجدولة المراقبة تلقائياً بعد الإقلاع.
- أمان محكم: تقييد حركة المرور غير المشفرة عبر `network_security_config.xml` وتعطيل الوصول إلى ملفات الجهاز في المتصفح الداخلي.
